# 开发路线图与里程碑 (Development Roadmap)

本文档规划了 `voice-input-buddy-windows` 从零到可发布产品的阶段性里程碑与详细开发任务。

---

## 一、阶段规划概览

```text
┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
│     Phase 1     │  ──>  │     Phase 2     │  ──>  │     Phase 3     │  ──>  │     Phase 4     │
│   核心链路 PoC   │       │   原生 UI 与向导 │       │   按键映射与增强 │       │   安装包与发布   │
└─────────────────┘       └─────────────────┘       └─────────────────┘       └─────────────────┘
  (控制台跑通全链路)         (WPF Fluent 主程序)       (自定义宏/多设备)         (Inno Setup 一键装)
```

---

## 二、详细里程碑划分

### Milestone 1: 核心音频与协议链路 PoC (Console / CLI)
**目标**：脱离复杂 UI，在纯 C# 控制台环境下跑通“蓝牙连接 -> 接收音频 -> 解码 -> 注入输入法”的端到端闭环。

- [ ] **项目骨架搭建**：
  - 初始化 `.NET 8` 解决方案结构 (`VoiceInputBuddy.sln`)；
  - 引入核心 NuGet 包：`NAudio`、`InTheHand.BluetoothLE` 或直接引用 WinRT API；
- [ ] **WinRT 蓝牙连接模块**：
  - 调用 `Windows.Devices.Bluetooth` 扫描并配对小米/Chromecast 遥控器；
  - 发现并订阅 `AB5E0001` 主服务下的 `Audio` (0003) 和 `Control` (0004) 特征值；
- [ ] **ATVV 握手与 ADPCM 解码**：
  - 写入 `GetCapabilities` 指令并解析返回参数；
  - 写入 `MicOpen` 指令启动流传输；
  - 编写并测试 `ImaAdpcmDecoder`，将接收的 4-bit 报文还原为 16kHz 16-bit 单声道 PCM；
- [ ] **WASAPI 音频推流**：
  - 使用 `NAudio.Wave.WasapiOut` 打开“CABLE Input”虚拟音频端点；
  - 实时写入 PCM 音频流，验证通过麦克风录音软件（如 Audacity 或 Windows 录音机）听到清晰人声；
- [ ] **热键注入原型**：
  - 监听控制台按键或遥控器按键，调用 `SendInput` 触发一次 `Win + H` 或微信输入法语音热键，在记事本中成功转写文字。

---

### Milestone 2: Windows 原生 UI 与设置向导 (Desktop GUI)
**目标**：构建拥有现代化 Fluent Design 质感的桌面客户端与新手引导向导。

- [ ] **WPF / WinUI 3 工程创建**：
  - 采用 `CommunityToolkit.Mvvm` 组织视图模型；
  - 集成 `WPF-UI` 控件库，支持 Windows 11 原生圆角、Mica 材质与深色/浅色模式切换；
- [ ] **四步式环境与设置向导 (Setup Wizard)**：
  1. **驱动检测**：检查 VB-CABLE 状态，支持一键引导安装/静默提权安装；
  2. **设备配对**：图形化列出系统已配对的蓝牙遥控器，直观展示信号强弱与连接状态；
  3. **语音与波形测试**：实时展示麦克风拾音 VU 表与音量动态波形；
  4. **输入法联动配置**：内置微信输入法、豆包输入法、Windows 听写工具的快捷键预设模板；
- [ ] **系统托盘与常驻后台**：
  - 支持关闭窗口最小化至系统托盘；
  - 托盘右键菜单包含快捷切换设备、重新运行向导、退出程序；
  - 开机自动静默启动（注册表 `Run` 键或开机任务计划）。

---

### Milestone 3: 按键映射引擎与增强特性
**目标**：将遥控器的其他按键充分利用起来，支持自定义快捷键与常用语输入。

- [ ] **Raw Input 全局按键拦截器**：
  - 监听 Consumer Control 报文，可靠捕获上下左右、OK、返回、主页、音量等物理键；
- [ ] **按键映射视图 (Key Mapping UI)**：
  - 可视化遥控器按键布局图（采用矢量 SVG 渲染）；
  - 点击对应按键可绑定：多媒体操作、系统组合键、常用文本短语；
- [ ] **Unicode 常用语快速上屏**：
  - 用户可在设置中配置固定短语，按下遥控器按键直接以 Unicode 形式注入输入框；
- [ ] **看门狗与异常恢复**：
  - 蓝牙短暂断连后的自动重连机制；
  - 长按说话丢失 KeyUp 时的超时保护释放。

---

### Milestone 4: 安装包封装与 CI/CD 自动化构建
**目标**：提供单个安装包（或绿色单文件），用户下载后一键搞定全套环境。

- [ ] **Inno Setup 脚本编写**：
  - 将主程序、依赖项以及已签名的 `VBCABLE_Setup_x64.exe` 一并打包为单一 `VoiceInputBuddy_Setup.exe`；
  - 安装过程中若检测到缺少虚拟音频驱动，调用静默安装命令；
  - 卸载时干净清理注册表、自启项与配置缓存；
- [ ] **GitHub Actions 工作流 (`.github/workflows/build.yml`)**：
  - 配置 `windows-latest` 编译环境；
  - 自动化执行 `dotnet publish` 并通过 Inno Setup 编译最终安装包；
  - 在 Release 页面自动发布构建产物。

## 三、开发技术规范

1. **零硬件依赖**：全流程不得引入专有硬件要求，所有测试均以电脑自带蓝牙 + 标准遥控器为准；
2. **代码风格**：遵循现代 C# 编码规范，全面开启可空引用类型（Nullable Reference Types），核心路径优先使用无分配或低分配技术（如 `Span<T>`）；
3. **隐私安全**：严格秉承 Voice Input Buddy 的产品原则：不采集用户语音历史、不上传遥控器按键统计、不设远程遥测（Telemetry）。
